# 04 - Post-Publication Editing, URL Stability & Downloads

## 1. Post-Publication Editing Rules
To protect hosted site performance and business rules:

### Free Text-Only Corrections
Users can correct typo errors and update event logistics without repurchasing:
- Event dates, times, schedules
- Host names, bride & groom names
- Venue addresses, directions text
- Descriptions and greetings

### Prohibited Design Changes
Free post-publication editing **cannot**:
- Move, resize, or delete canvas elements
- Change fonts, colors, background SVGs, or theme palettes
- Add new interactive components or reorder pages

---

## 2. Canonical URL Stability
- Once published, normal republishing preserves the exact same public URL.
- Bookmarks, shared WhatsApp links, printed QR codes, and guest messages continue to resolve seamlessly.

---

## 3. Published Invite Actions
A published Invite unlocks a dedicated action suite in the creator dashboard:
1. **Copy URL**: Instant one-click clipboard copy.
2. **Share URL**: Opens native OS / browser share dialog (WhatsApp, Messages, Social).
3. **Generate QR Code**: URL-based QR code download for physical invitation card printing.
4. **Download Artwork**: Entitlement-based exports.

---

## 4. Download Entitlements Matrix
- **Basic (₹49)**: Download not included. User can upgrade to Premium.
- **Premium (₹99)**:
  - *Single-page Invites*: High-res PNG Image + Vector PDF.
  - *Multi-page Invites*: Full multi-page Vector PDF.

---

## 5. Duplicate / Copy to New Flow
- Creates an independent duplicate of the Invite with a **new Invite ID**.
- Allows deep design redesigns while leaving the original published microsite live and untouched.
