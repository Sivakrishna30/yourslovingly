# 06 - Analytics & Interactive Feature Architecture

## 1. Invite Analytics Philosophy
Yours Lovingly provides privacy-first, simple, and meaningful insights without invasive surveillance or advertising pixels.

### Included Metrics:
- **Total Views**: Raw page load count.
- **Unique Visitors**: Approximate distinct devices viewing the microsite.
- **Views Over Time**: Daily/hourly engagement chart leading up to the event date.
- **RSVP Activity**: Real-time summary of attending vs. declined guests and responses.

### Explicitly Excluded (Anti-Tracking Principles):
- ❌ No visitor GPS location tracking.
- ❌ No biometric or device fingerprinting.
- ❌ No payment/UPI transaction logging.
- ❌ No invasive third-party ad pixels.

---

## 2. Interactive Components Suite

### 2.1 Interactive RSVP Form
- **Standard Toggle**: Attending / Not Attending.
- **Custom Question Builder**:
  - Multiple Choice (e.g. Meal Preference: Veg / Non-Veg / Vegan)
  - Number of Guests / Plus-Ones
  - Open Text (e.g. "Song requests or blessings for the couple")
- **Dashboard Synchronization**: Responses aggregate into a downloadable guest list.

### 2.2 Google Maps Embed
- Interactive vector map centered on the venue pin.
- One-touch "Get Directions" button launching Google Maps / Apple Maps on guest mobile devices.

### 2.3 Spotify Music Embed
- Curated background song embedded directly into the invite header or floating audio control.

### 2.4 UPI Scanner / Direct Payment QR
- Displays custom UPI QR linked directly to the creator's VPA / UPI ID for digital cash gifts (shagun) without platform transaction cuts.
