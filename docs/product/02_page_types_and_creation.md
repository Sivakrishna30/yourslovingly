# 02 - Invite Types & Creation Experience

## 1. Supported Invite Types
The product natively supports four primary invite types:

1. **Digital Invitation**:
   - For Weddings, Engagements, Birthdays, Anniversaries, Housewarmings, Baby showers, Naming ceremonies, Receptions, Parties, and Custom events.
2. **Digital Business Card**:
   - For Businesses, Professionals, Freelancers, Studios, Shops, Gyms, and Boutiques.
3. **Digital Flyer / Pamphlet**:
   - For Promotions, Product launches, Announcements, Workshops, Offers, and Local campaigns.
4. **Digital Portfolio**:
   - For Photographers, Designers, Creators, Freelancers, and Professionals.

---

## 2. Event Types & Custom Event Names
The initial invitation creation flow supports 10 distinct event types:
1. Wedding
2. Engagement
3. Birthday
4. Anniversary
5. Housewarming
6. Baby Shower
7. Naming Ceremony
8. Reception
9. Party
10. Custom Event

### Editable Default Names
Selecting an event type populates a default name (e.g., "Wedding"), but this is purely a default. The user can edit the event name to anything they choose (e.g., "Nikah", "Sangeet", "House Blessings", or custom celebration names).

---

## 3. Core Creation Experience
The minimum creation journey is completely frictionless:
```text
Create 
   ↓ 
Select Invite Type 
   ↓ 
Select Event Type 
   ↓ 
Select Template 
   ↓ 
Enter Details 
   ↓ 
Preview 
   ↓ 
Edit 
   ↓ 
Publish
```
The user is never exposed to complex infrastructure, deployment settings, DNS configs, or code.

---

## 4. Template-First Experience & Design Freedom
- **Template-First**: Users never start from an intimidating blank canvas. Templates provide the initial layout, typography, colors, visual hierarchy, and element arrangements.
- **Complete Freedom**: Nothing in a template is permanently locked. The template is a starting point, not a restriction.
- **Editable Properties**: Position, size, font family, font size, weight, colors, background styling, theme tokens, content, element placement, element visibility, and individual element configurations.
